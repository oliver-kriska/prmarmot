# Separate agent-authored PRs and show whether a human has looked yet
category: Ideas

Today: agent-authored PRs sit inline with human ones in both views and the app cannot tell them apart. Five named agents opened over 159,000 public PRs in August 2026.

PRs opened by Copilot coding agent, Claude Code, Codex, Cursor, Devin and similar would be detectable (bot accounts plus configurable author patterns), filterable into their own group, and carry a state "no human has reviewed this yet". Read-only: it triages, it does not judge.

Vote with 👍 if agent PRs are crowding your queue. Comment with which agents you see and how they show up (bot account, trailer, label).
