# Say *why* a PR needs you: the failing check, the person, the thread
category: Ideas

Today: the Note says "CI failing", "changes requested" or "2 unresolved threads", and the CLI types the blocker, but neither names the check, the person or the thread.

The Note would name the evidence: which check is red, who requested changes, which thread is unresolved, who has not responded to a review request. The app, the CLI, the dock badge and notifications would use the same words and the same order.

Vote with 👍. Comment if there is a reason you keep having to click through to find.
