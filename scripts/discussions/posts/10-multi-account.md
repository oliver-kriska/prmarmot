# Two GitHub accounts, one board
category: Ideas

Today: PR Marmot uses whichever `gh` account is active, so work and personal accounts mean two windows or a switch.

Both accounts' PRs in one window with an account badge per row, one search per account per refresh, rate-limit budget shown per account. This is the most-upvoted unbuilt request in the GitHub tooling ecosystem (981 👍 on GitHub Desktop, 354 👍 on the GitHub CLI, both still open).

Vote with 👍 if you juggle two accounts. Comment with whether they are on github.com or an Enterprise host.
